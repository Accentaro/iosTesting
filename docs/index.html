Valenced iOS Testing

Experimental iOS builds of Declutter, Quoter and CollapsibleUI, version 1.0.5.

In Valenced, open Settings ? Plugins ? Advanced ? Add repository and paste:

https://accentaro.github.io/iosTesting/

Open Browse Plugins, install the plugins labelled ?(iOS Test)?, enable them and restart Discord.

These keep the original plugin IDs and settings and replace the installed copies. They have passed local build checks but need testing on iOS.

Test Quoter previews and sending, Declutter dragging and visibility controls, and CollapsibleUI collapsing and restoring the chat input and You bar.
